自然言語で会計

Claude や Cursor などの AI から「A社に請求書を発行して」「先月の売上は？」と話すだけ。発行・送付・入金記録・集計まで会話で完結します（MCP対応）。もちろん画面からの操作も。

運用コスト 0円

Cloudflare の無料枠だけで動くよう設計されています。請求書ツールやクラウド会計の月額 1,000〜5,000円が、そのまま消えます。メール送付も無料枠（Resend 月3,000通）で十分。

OSSだから、自分のもの

MITライセンスで公開。データは自分の Cloudflare アカウントの中にあり、サービス終了や値上げに振り回されません。エンジニアがいればカスタマイズも自由です。

導入は、ターミナルに1行

エンジニアでなくても大丈夫。質問に答えていくだけで、あなた専用のURLが発行されます。

1

コマンドを貼り付ける

npm create invoice-harness@latest

Node.js 22+ が必要です（nodejs.org から無料）

2

質問に答える

プロジェクト名・管理者メールなどを対話で入力。無料の Cloudflare ログインがブラウザで開きます。

3

自分のURLができる

https://あなたの名前.pages.dev が発行され、初期セットアップウィザードが案内します。

こわい人へ: クラウドに何も作らない「ローカルお試しモード」も選べます。

AIとつなぐ（MCP）

MCP（Model Context Protocol）対応のAIツールならどれでもつながります。Claude、Cursor、Cline、Gemini CLI、VS Code など。各ツールのMCP設定ファイルに右のJSONを貼るだけです。

Claude Cursor Cline Gemini CLI VS Code

{ "mcpServers": { "invoice-harness": { "command": "npx", "args": ["-y", "@invoice-harness/mcp-server"], "env": { "IH_API_URL": "https://あなたの.pages.dev", "IH_API_TOKEN": "（設定 ▸ API/連携で発行）" } } } }

Claude Code なら claude mcp add の1コマンド。各ツールのMCP設定ファイルに上記を貼るだけです。

よくある質問

本当に無料ですか？

アプリ本体は Cloudflare の無料枠（Pages・D1・R2）内で動きます。個人〜小規模チームの利用で枠を超えることはまずありません。超えた場合も課金は自分の Cloudflare アカウントに対してで、当プロジェクトへの支払いは一切ありません。

データはどこに保存されますか？

あなた自身の Cloudflare アカウント内のデータベース（D1）です。運営者のサーバーというものが存在しないため、第三者にデータを預けません。バックアップのエクスポート／復元機能もあります。

エンジニアがいなくても使えますか？

導入はコマンド1行＋質問に答えるだけです。日々の利用は普通のWebアプリと同じで、初期設定はウィザードが案内します。

法令面の対応は？

インボイス制度（適格請求書発行事業者番号・税率別内訳）、源泉徴収、収入印紙の自動判定に対応しています。申告・決算の最終確認は税理士にご相談ください。
